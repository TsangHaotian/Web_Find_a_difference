# Web Find the Difference Game 🕵️‍♂️

An online "Find the Difference" game built with HTML/CSS/JavaScript, featuring a timer.

## 🎮 Game Features

- **Classic Two-Column Layout**: Side-by-side image comparison.
- **Interactive Feedback**: Real-time click responses and sound effects.
- **Dynamic Scoring**: Tracks correct and incorrect attempts.
- **60-Second Challenge**: Time-limited gameplay mode.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 🚀 Quick Start

### Run in Browser
Visit: https://tsanghaotian.github.io/Web_Find_a_difference/

### Run Locally
```bash
git clone https://github.com/TsangHaotian/Web_Find_a_difference.git
cd Web_Find_a_difference
# Simply double-click index.html to open it in your browser
```
